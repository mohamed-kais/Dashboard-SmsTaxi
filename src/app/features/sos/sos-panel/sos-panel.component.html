Alert protocol (reference)

Standard contact flow when an SOS is triggered — for operator reference only; the dashboard cannot track alert state yet.

  1. Driver triggers the SOS button from the taxi application.
  2. Backend sends an SMS alert for the taxi ID (POST /api/sosNotification/{id}).
  3. Dispatch receives the alert and calls the driver to confirm the situation.
  4. If the driver cannot be reached, escalate to emergency services.
  5. Log the incident outcome in the operations record.
